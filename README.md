# IDOL COLLECTION

黒×紫ネオンをテーマにした、iPhone横画面向けの個人用アイドルカード収集アプリです。GitHub Pagesで公開し、ブラウザ内にデータを保存します。

## 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作成します。
2. ZIP内のファイルをすべてリポジトリのルートにアップロードします（`index.html` が一番上の階層にある状態）。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、`main` ブランチの `/ (root)` を指定して保存します。
5. 公開されたURLをiPhoneのSafariで開きます。
6. Safariの共有メニューから「ホーム画面に追加」を選ぶと、アプリのように起動できます。

## 主な機能

- ホーム、ガチャ、図鑑、ライブ、登録の5画面
- 写真をアプリ内にコピーし、JPEGに自動最適化して保存
- カード登録・編集・登録削除
- 単発・10連ガチャ、ランク別排出率、未登録ランクの比例再配分
- 重複カードの所持枚数管理
- 手動覚醒（同じ登録カードを1枚消費、最大10回）
- ライブ参加者を毎回手動で最大10人選択し、50回の応援タップで経験値獲得
- 図鑑の検索・ランク/属性フィルター・4種類の並び替え（昇順/降順）
- 画像込みのバックアップ書き出し・復元
- 初回アクセス後のオフライン起動（Service Worker対応）

## 仕様メモ

- チケットは1時間に1枚、最大30枚。アプリを閉じている間も経過時間で回復します。30枚満タンの間は回復時間を貯めません。
- SR 10%、R 30%、N 60%。未登録ランクの確率は登録済みランクの元の重みに比例して再配分します。
- ライブはスタミナ消費なし、1回50タップ。参加者全員に同じ固定経験値490を付与します。レベルごとの必要経験値を100とし、SRはLv.1からライブ10回でLv.50に到達します。上限に達したキャラは経験値を獲得しません。
- SR/R/Nの初期レベル上限は50/40/30。覚醒1回ごとに上限+1、最大10回。覚醒時はレベルを維持します。
- 「解雇」は所持分とその育成データを削除し、図鑑の登録情報は残します。「登録削除」はカード定義と関連所持データを削除します。
- 復元は現在のデータをバックアップ内容に完全置換します。復元前に現在データをバックアップしてください。

## 保存とプライバシー

データはこのブラウザのIndexedDBに保存され、サーバーには送信されません。ブラウザのサイトデータを削除すると失われる可能性があります。定期的にバックアップしてください。画像の大量登録ではブラウザの保存容量上限に達することがあります。

## 注意

これは個人用の初期版です。端末やブラウザの仕様により、バックアップファイルが大きい場合や保存容量が不足している場合は、書き出し・復元に失敗することがあります。初回のオンラインアクセス後にService Workerがキャッシュを作るため、完全なオフライン動作には一度オンラインで開く必要があります。
